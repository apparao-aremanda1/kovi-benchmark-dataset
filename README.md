Kovi AI — Technical Evaluation & Benchmark Dataset
Open-source benchmark dataset comparing automated AI voice interviewer evaluations (generated by Kovi from TechEval) against human engineering panel reviews.

This repository provides structured, anonymized interview transcripts, multi-dimensional scoring rubrics, and qualitative evaluator notes designed to support research, transparency, and validation in AI-driven technical recruitment.

📊 Dataset Overview
Evaluating conversational AI agents in high-stakes domains like technical hiring requires transparent data. This dataset captures complete interview cycles—from initial technical prompts to final human verdict rationales.

Primary AI Agent: Kovi AI Voice Interviewer

Evaluation Scale: 1 to 10 across core engineering competencies

Data Format: Clean, structured JSON records

Validation Target: Evaluating scoring correlation, domain accuracy, and automated decision-making against human engineering panels.
